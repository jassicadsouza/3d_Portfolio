**Portfolio Website**

An interactive and fully responsive portfolio website built with TypeScript, Three.js and Tailwind CSS, featuring immersive 3D elements, smooth animations, and a modern user interface. Designed to showcase my projects, skills, and experience while delivering an engaging user experience across all devices.

**Features**
1. Modern and responsive design
2. Interactive 3D elements and animations
3. Built with TypeScript for type safety and maintainability
4. Optimized for performance and user experience
5. Mobile-friendly and cross-browser compatible
6. Showcases projects, skills, and contact information

**Tech Stack**: TypeScript, Three.js, Tailwind CSS, JavaScript

**Getting Started:**
```bash
git clone https://github.com/jassicadsouza/3d_Portfolio
cd portfolio
npm install
npm run dev
```
